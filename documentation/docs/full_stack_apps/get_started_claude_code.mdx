# Get Started (with Claude Code)

Build a full-stack app — a Reboot backend behind a standalone React
frontend served at a normal URL — using
[Claude Code](https://docs.anthropic.com/en/docs/claude-code/overview)
and the Reboot plugin. Claude Code writes the code for you: you
describe what you want, approve the plan, and it scaffolds the
entire project.

## Install the Reboot plugin

The plugin bundles everything Reboot needs, so
[Claude Code](https://docs.anthropic.com/en/docs/claude-code/overview)
itself is the only thing you need to have installed.

<Tabs groupId="install-method">
  <TabItem value="quick" label="Quick install">

Install the Reboot plugin for Claude Code with a single
command:

```sh
curl -fsSL https://reboot.dev/install.sh | bash
```

This registers the Reboot marketplace, installs the plugin,
and pre-installs its pinned dependencies so your first build
runs without waiting on downloads.

Then start Claude Code — or, if it was already running while you
installed, restart it — so the plugin loads.

  </TabItem>
  <TabItem value="manual" label="Manual install">

Add the marketplace and install the plugin yourself with
Claude Code:

```
claude plugin marketplace add reboot-dev/reboot-plugin
```

```
claude plugin install reboot@reboot-plugin
```

Or, to auto-enable the plugin for your whole team, add this to your
project's `.claude/settings.json`:

```json
{
  "extraKnownMarketplaces": {
    "reboot-plugin": {
      "source": {
        "source": "github",
        "repo": "reboot-dev/reboot-plugin"
      }
    }
  },
  "enabledPlugins": {
    "reboot@reboot-plugin": true
  }
}
```

Restart any Claude Code session that was already running when you
installed the Reboot plugin so the new plugin loads.

  </TabItem>
</Tabs>

## Use the skill

Once installed, invoke the skill with a description of your app:

```
/reboot:web-app Build a web app where users can sign up and keep a list of chat rooms
```

You can also just describe what you want to build in a normal
prompt — Claude Code selects the right Reboot skill from your
description, and saying "website", "web app", "SPA", "in the
browser", or naming a URL is enough for it to pick the Web App
builder. Or invoke `/reboot:app`, which asks whether you want an AI
Chat App or a standalone Web App and then hands off to the matching
skill — for this guide, pick the Web App.

The skill settles the design before it writes any code. It will:

1. Analyze your description and propose a state model
2. Map out which types and methods your app needs, which pages the
   frontend has, and how users sign in
3. State that design back to you — so you can redirect it before
   the code exists

Claude Code then scaffolds the full project — API definition,
backend servicers, React SPA, and configuration — builds it, writes
and runs backend tests, and starts the app.

:::info The agent-driven path builds a Python backend
The skill scaffolds a Python backend with a React frontend. If you
want a **TypeScript** backend, follow the hand-written
[TypeScript guide](/full_stack_apps/typescript) instead — but note
that TypeScript backend support is in alpha.
:::

## What gets created

The skill generates a complete full-stack Reboot app. The most
relevant files are:

```
my-app/
├── .rbtrc                    # Reboot CLI config
├── pyproject.toml            # Python deps (uv)
├── api/
│   └── my_app/v1/
│       └── my_app.py         # API definition (Pydantic)
├── backend/
│   ├── api/                  # Generated Python bindings
│   ├── src/
│   │   ├── main.py           # Application entrypoint
│   │   └── servicers/
│   │       └── my_app.py     # Servicer implementation
│   └── tests/
│       └── my_app_test.py    # Backend behavior tests
└── frontend/
    ├── package.json
    ├── build.mjs             # Discovers + builds every UI
    ├── vite.config.ts        # Vite dev server + build config
    ├── index.css             # Theme variables
    ├── api/                  # Generated React bindings
    └── web/                  # The standalone browser SPA
        ├── index.html
        ├── .env.development  # VITE_REBOOT_URL=http://localhost:9991
        └── src/
            ├── main.tsx      # RebootClientProvider entry
            └── App.tsx       # Routes + top-level component
```

Each entity your app manages becomes its own
[durable state type](/learn_more/define/overview) with its own
methods; the frontend calls those methods through the typed
[React hooks](/learn_more/call/from_react) that `rbt generate`
emits into `frontend/api`. If your app has per-user state, the
skill also declares a `User` type and signs browser users in
through Reboot's [built-in OAuth support](/learn_more/auth) —
`Development()` in development, so you can sign in as any
identity without registering a provider first.

## Test your app

Claude Code writes backend unit tests covering your app's user
stories and runs them before handing the app off — they help to
make sure that your app works, and keeps working.

Once the tests pass, Claude Code starts everything the app needs:

* the Reboot backend (`rbt dev run`), which serves your API at
  `http://localhost:9991`, and
* the Vite dev server, on `http://localhost:4444`.

It then hands you `http://localhost:4444`, which redirects to your
web app. In development, click "Sign in" and pick (or make up) a
`Development` identity; signing in auto-constructs your `User`.

## Iterate on your app

You can also use the skill to modify an existing app:

```
/reboot:web-app Add a page that shows the messages in a single chat room
```

The skill reads your current code, plans the changes, and waits
for approval before editing.

## Run it again later

If you come back to your project in a new session, ask Claude Code
to bring the app back up:

```
/reboot:run my-app
```

Or just say "Run this Reboot app" from the project directory. The
run skill starts the backend and the frontend dev server and points
you at the app.
