# navy-pastel-workspace

## Character
A confident all-in-one workspace: white canvas, warm charcoal ink and 8px rectangular buttons with a purple primary. Deep navy can anchor the sidebar or a dark header; pastel tints (peach, rose, mint, lavender, sky, yellow) colour tags, status and grouped cards like database properties. Inter runs every role at sensible app sizes. Shapes are sober: 8px controls, 12px cards, pill tabs and badges.

## Color roles
- Page canvas: `{colors.canvas}`; side panels and table headers `{colors.surface}`; dark sidebar `{colors.brand-navy}` with `{colors.on-dark}` text
- Raised surface (cards, panels, drawers): `{colors.canvas}` with a `{colors.hairline}` border; wells `{colors.surface-soft}`
- Hairline and borders: `{colors.hairline}`; dividers `{colors.hairline-soft}`; field borders `{colors.hairline-strong}`
- Text primary: `{colors.ink}`; secondary: `{colors.charcoal}`; muted: `{colors.steel}`; disabled `{colors.muted}`
- Primary action: `{colors.primary}` fill with `{colors.on-primary}` text; pressed `{colors.primary-pressed}`
- Secondary action: transparent with `{colors.hairline-strong}` border and `{colors.ink}` text
- Link: `{colors.link-blue}`
- Focus ring: `{colors.primary}`
- Selected / active: `{colors.ink-deep}` fill on pill tabs; selected rows `{colors.card-tint-lavender}` with a `{colors.primary}` edge
- Error: `{colors.semantic-error}`

**Status accents** (tint fill, dark text, with a label):
- Good: `{colors.brand-green}` on `{colors.card-tint-mint}`
- Attention: `{colors.brand-orange-deep}` on `{colors.card-tint-peach}`
- Problem: `{colors.semantic-error}` on `{colors.card-tint-rose}`
- In progress: `{colors.brand-purple-800}` on `{colors.card-tint-lavender}`
- Info / scheduled: `{colors.link-blue}` on `{colors.card-tint-sky}`
- Neutral: `{colors.steel}` on `{colors.card-tint-gray}`

## Type roles
- Page title: `{typography.heading-3}`
- Section heading: `{typography.heading-4}`; panel heading `{typography.heading-5}`
- Item / card title: `{typography.body-md-medium}`
- Body: `{typography.body-sm}` in dense views, `{typography.body-md}` in reading views
- UI label: `{typography.body-sm-medium}`; buttons `{typography.button-md}`
- Caption / meta: `{typography.caption}`; column headers `{typography.micro-uppercase}`
- Numbers: `{typography.body-sm-medium}` with Inter tabular figures; KPI tiles `{typography.heading-2}`

`{typography.hero-display}`, `{typography.display-lg}` and `{typography.heading-1}` (48 to 80px) are for one rare headline figure, never page titles.

## Shape and density
- Controls: buttons and inputs `{rounded.md}`; ghost buttons and tags `{rounded.sm}`; tabs and badges `{rounded.full}`.
- Cards and panels: `{rounded.lg}`; dialogs `{rounded.xl}`.
- Spacing on a 4px base: `{spacing.xs}` inside controls, `{spacing.sm}` between fields, `{spacing.md}` board card padding, `{spacing.xl}` panel padding, `{spacing.xxl}` between regions. Section and hero spacing have no use in an app.
- Tables: 40px rows, `{spacing.md}` by `{spacing.lg}` cell padding, `{colors.hairline-soft}` row rules. Boards: `{spacing.xs}` card gaps, tinted column headers.
- Depth: hairlines first; a soft diffuse shadow only on menus, popovers, dialogs and dragged cards.

## Do / Don't
Do:
- Keep buttons as 8px rectangles and the primary purple.
- Use the pastel tints as property and status colours, with dark text.
- Use the navy for one anchoring area, such as the sidebar.
- Use tabular figures in tables and KPI tiles.
- Keep page titles at 28px and below.

Don't:
- Don't use the 48 to 80px display sizes as headings.
- Don't put white text on pastel tints.
- Don't use more than one solid badge colour per row.
- Don't add drop shadows to cards in the page flow.
- Don't carry status by colour alone.
