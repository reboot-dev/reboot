# Looks

DESIGN.md files (the Google Stitch format: YAML tokens, then a short guide to using them in an app), one per look, its tokens in both themes (the other theme under `colors-dark:` or `colors-light:`). Every look defines the same app components, by the same names (its guide's "Components" lists them), so a page is built the same way whatever the look. Twenty looks, chosen for range. Each has a light and a dark theme: its own, and the other under `colors-dark:` or `colors-light:`. Read this index; read one look in full only once it is chosen.

**ops fit** is how well a look suits a dense staff tool used all day (boards, tables, timelines), 5 best. A staff-facing app picks from 4 and 5; a consumer-facing app can go lower for character.
