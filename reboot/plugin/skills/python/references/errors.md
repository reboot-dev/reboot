## Look Up an Error

When a build hits an error string (a traceback line, a `<Method>Aborted`,
a `mypy` message, a `reboot.bdd` "Almost" match, a startup refusal), grep
this file for a distinctive fragment of it before guessing which concept
it belongs to. Search for a fragment, not the whole line, since paths
and ids vary, and never read the file whole:

```sh
grep -i "StateNotConstructed" <plugin>/skills/python/references/errors.md
```

Each row gives what the error means, the fix, and the file to read for
the full story. A miss means the error isn't listed here, not that it
can't happen.
